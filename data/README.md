# Data

This folder holds the GFP fluorescence landscape used to train Aurora's oracle.
**Nothing here is committed to git** (the whole folder is `.gitignore`d) — datasets
are big and the licensing is cleanest if everyone pulls from the original source.
Reconstruct it with the one command below.

## What it is

Point mutants of **avGFP** (Aequorea victoria green fluorescent protein), each with a
measured brightness. The label is `log_fluorescence` (higher = brighter). Variants
range from 1 to ~15 mutations away from the wild-type.

- **Original experiment:** Sarkisyan et al. (2016), *Local fitness landscape of the
  green fluorescent protein*, Nature 533:397.
- **Curation + splits:** the TAPE benchmark (Rao et al. 2019).
- **What we download:** the HuggingFace mirror `biomap-research/fluorescence_prediction`
  (Apache-2.0). If it ever moves, `cradle-bio/tape-fluorescence` and
  `SaProtHub/Dataset-Fluorescence-TAPE` carry the same data — swap the name in
  `src/aurora/data.py`.

## The split (read this before you model)

TAPE splits **by edit distance from wild-type**, not randomly:

| split        | variants        | mostly |
|--------------|-----------------|--------|
| train + valid | ≤ 3 mutations   | bright (~82%) |
| test         | ≥ 4 mutations   | dark (~32% bright) |

This is deliberate. The oracle learns on a small bright neighborhood and is judged on
a farther, mostly-dark region it never saw — a genuine extrapolation test. **Do not
reshuffle train and test together;** a random split leaks near-duplicate variants
across the boundary and inflates every number you report. The primary metric is
Spearman rank correlation on the test set.

## How to get it

From the repo root, with the environment synced (`uv sync`):

```bash
uv run python -m aurora.data
```

This downloads the dataset once, normalizes it, and writes `data/processed/gfp.csv`
with columns: `sequence`, `log_fluorescence`, `num_mutations`, `split`. Later loads
read the cached CSV, so it's instant and works offline. Delete the CSV (or call
`load_gfp(force_download=True)`) to refresh.

## Files

- `raw/` — untouched downloads, if you ever pull the original TAPE/Sarkisyan files.
- `processed/gfp.csv` — the normalized table the code actually reads. Regenerated by
  the command above; safe to delete.
