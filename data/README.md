# Data

The GFP fluorescence data the oracle trains on. None of it is committed. The whole
folder is gitignored because the files are large and it is simpler to pull from the
source. One command rebuilds it.

## What it is

Point mutants of avGFP (Aequorea victoria green fluorescent protein), each with a
measured brightness. The label is `log_fluorescence`, higher is brighter. Variants
run from 1 to about 15 mutations off the wild-type.

- Experiment: Sarkisyan et al. 2016, *Local fitness landscape of the green
  fluorescent protein*, Nature 533:397.
- Curation and splits: the TAPE benchmark (Rao et al. 2019).
- What we download: the HuggingFace mirror `biomap-research/fluorescence_prediction`
  (Apache-2.0). If it disappears, `cradle-bio/tape-fluorescence` and
  `SaProtHub/Dataset-Fluorescence-TAPE` hold the same data. Swap the name in
  `src/aurora/data.py`.

## The split

TAPE groups variants by edit distance from the wild-type.

| split         | variants             | mostly             |
|---------------|----------------------|--------------------|
| train + valid | 3 or fewer mutations | bright (~82%)      |
| test          | 4 or more mutations  | dark (~32% bright) |

The oracle learns from the bright local neighborhood and is measured on the farther,
mostly-dark region it did not see during training. That measures extrapolation. If
train and test are combined and reshuffled, near-duplicate variants land on both
sides of the boundary and the reported scores are inflated, so the split is kept as
is. Headline metric is Spearman on the test set.

## Getting it

From the repo root, environment synced (`uv sync`):

```bash
uv run python -m aurora.data
```

Downloads once, normalizes, and writes `data/processed/gfp.csv` with columns
`sequence`, `log_fluorescence`, `num_mutations`, `split`. Later runs read the cached
CSV, which works offline. Delete the CSV (or call `load_gfp(force_download=True)`) to
refresh.

## Files

- `raw/`. Untouched downloads, if you ever pull the original TAPE or Sarkisyan files.
- `processed/gfp.csv`. The normalized table the code reads. Regenerated by the command
  above. Fine to delete.
